# Generating Android Signing Certificate Hashes for FreeRASP

To protect your Android application, FreeRASP requires the SHA-256 hashes of the certificates used to sign your app. You need to provide hashes for **both** your Debug and Release environments.

## 1. Prerequisites

- You need the Java Development Kit (JDK) installed (which includes `keytool`).
- You need access to your terminal.
- You need to know where your `debug.keystore` and release keystore (e.g., `upload-keystore.jks` or similar) are located.

## 2. Generate Hash for Debug (Development)

The debug keystore is automatically generated by Android tools and is typically located at `~/.android/debug.keystore`.

**Run this command in your terminal:**

```bash
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
```

**What to look for:**
Look for the **SHA-256** fingerprint in the output. It will look like a long string of hex numbers (e.g., `AA:BB:CC...`).

**Convert to Base64 (Optional but often required by FreeRASP config):**
FreeRASP configuration in Dart expects the hash as a string. Depending on the plugin version, it might accept the hex string (with colons removed) or base64. **For now, copy the SHA-256 value exactly as displayed.**

## 3. Generate Hash for Release (Production)

This depends on how you sign your app for the Play Store.

### Scenario A: You manage your own Release Keystore
If you have a `.jks` or `.keystore` file that you use to build your release APK/app bundle:

**Run this command:**

```bash
keytool -list -v -keystore <path-to-your-release-keystore> -alias <your-key-alias>
```

*You will be prompted for the keystore password.*

**Copy the SHA-256 fingerprint.**

### Scenario B: Google Play App Signing (Most Common)
If you let Google manage your keys (you upload an `.aab`):

1. Go to the **Google Play Console**.
2. Select your app.
3. Go to **Release** > **Setup** > **App signing**.
4. Look for "App signing key certificate".
5. Copy the **SHA-256 certificate fingerprint**.

## 4. Provide the Hashes

Please provide the **SHA-256 hashes** for:
1. **Debug**: (From Step 2)
2. **Release**: (From Step 3 - preferably from Play Console if using App Signing)

---
> [!NOTE]
> If you are on a Mac and standard `keytool` commands don't work, ensure you have Java installed and in your PATH. You can check with `java -version`.
