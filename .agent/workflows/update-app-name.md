# Update App Name

*   Once user provides the **App Name** and **Package Name** (e.g., "My Finance App", "com.example.finance") from [Start New Flutter App](start-new-flutter-app.md), update all docs with the information provided, replacing "Bizzie", "bizzie", or "App Name" (for widget names and docs) with the user's input. 
*   If the app name that the user provides has spaces -- ensure the spaces are removed where necessary in docs so that the code doesn't break when agents generate code based on the app name. 

*   If user provides incorrectly formatted package name, provide guidance on how to fix.
