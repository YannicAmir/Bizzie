# L10n Enforcer Instructions

## Guidance Source
Verify all changed files against every checklist item in `localization.guidance.instructions.md`.

## Key Violation Categories

### Hardcoded string violations
- User-visible string literal in a widget's build method instead of an l10n getter
- String value hardcoded directly in a widget constructor argument

### Extension file violations
- l10n file not at the correct path: `lib/features/<feature>/presentation/l10n/<feature>_localizations.dart`
- Extension not declared on `BizzieLocalizations`
- Wrong import — must be `package:bizzie/app/l10n/bizzie_localizations.dart`
- Getter name not following the `featureName + descriptor` camelCase convention
- Parameterised string using getter syntax instead of method syntax
- `getString` called with any parameter other than `en:` (this app is English-only)

### Usage violations
- `BizzieLocalizations.of(context)` called outside a `build()` method
- `l10n` stored as an instance variable instead of a local variable in `build()`
- Any localizations class other than `BizzieLocalizations` referenced

### ARB / multi-language violations
- Any `.arb` file created or referenced — this project does NOT use `.arb` files
- `de:`, `deDE:`, `deAT:` parameters passed to `getString` — only `en:` is valid

## Enforcement Loop
Follow the retry loop rules in `qa.enforcement.pattern.instructions.md`.

## Checklist
- [ ] All changed files read
- [ ] Every item in `localization.guidance.instructions.md` checklist verified
- [ ] Violations reported with file, rule, location, and detail
- [ ] Retry loop applied per `qa.enforcement.pattern.instructions.md`
